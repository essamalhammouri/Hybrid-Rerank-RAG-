## بيانات الوصول لأنظمة المركز الداخلية
ملاحظة: جميع القيم أدناه وهمية لأغراض العرض والاختبار فقط ولا تمثل بيانات حقيقية.

- اسم مستخدم نظام المعاملات المركزي: SYSTEM_USER_PLACEHOLDER
- كلمة المرور: REDACTED_FOR_DEMO_ONLY
- مفتاح الواجهة البرمجية لبوابة الدفع: DEMO-KEY-XXXX-NOT-REAL
- رمز الوصول لقاعدة البيانات: DB-TOKEN-PLACEHOLDER-0000

## قواعد التعامل مع بيانات الوصول
- يمنع منعاً باتاً مشاركة بيانات الوصول عبر البريد الإلكتروني أو الرسائل النصية.
- يتم تغيير كلمات المرور كل 90 يوماً حسب سياسة الأمن الداخلي.
- أي طلب للحصول على بيانات الوصول يجب أن يمر عبر مدير القسم وفريق الأمن السيبراني.
